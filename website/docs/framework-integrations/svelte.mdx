# Svelte

[Svelte][] components for the Uppy UI plugins.

## Install

<Tabs>

npm install @uppy/svelte
```

  </TabItem>

  <TabItem value="yarn" label="Yarn">

```

  </TabItem>

:::note

You also need to install the UI plugin you want to use. For instance,
`@uppy/dashboard`.

:::

## Use

Uppy offers three ways to build user interfaces:

1. **Pre-composed, plug-and-play components.** Mainly `<Dashboard />`. The
   downside is that you can’t customize the UI.
2. **Headless components** (Svelte 5 only). Smaller components, easier to
   override the styles or compose them together with your own components.
3. **Hooks** (Svelte 5 only). Attach our logic to your own components, no
   restrictions, create a tailor-made UI.

### Components

Pre-composed, plug-and-play components:

- `<Dashboard />` renders [`@uppy/dashboard`](/docs/dashboard)
- `<DashboardModal />` renders [`@uppy/dashboard`](/docs/dashboard) as a modal
- `<StatusBar />` renders [`@uppy/status-bar`](/docs/status-bar)

:::note

`<DragDrop />` and `<ProgressBar />` were removed in Uppy 5.0. Use the headless
[`<Dropzone />`](#dropzone-) component or the
[`useDropzone`](#usedropzoneoptions) hook instead (Svelte 5 only). The
[`@uppy/drag-drop`](/docs/drag-drop) plugin itself is still supported for setups
without a framework.

:::

### Headless Components

:::tip

Play around with the Svelte headless components in StackBlitz

:::note

All components must be placed within a `UppyContextProvider`. Headless
components only work with Svelte 5

:::

Uppy’s headless components are smaller and more flexible. All components must be
placed within a `UppyContextProvider`. They come styled as well but you can
override the styles with data attributes, for example with `UploadButton`:

```css
button[data-uppy-element='upload-button'][data-state='uploading'] {
  background-color: lightblue;
}
```

#### `UppyContextProvider`

Provides Uppy context to child components and manages global upload
status/progress.

```svelte
<script>
  import { UppyContextProvider } from '@uppy/svelte';
  import Uppy from '@uppy/core';

  const uppy = new Uppy();
</script>

<UppyContextProvider {uppy}>
  <!-- Your components and/or Uppy components -->
</UppyContextProvider>
```

## Examples

The prop getters of `useImageEditor` return Svelte event attributes
(`onclick`, `onchange`, `onload`), so you can spread them on elements. Don’t
destructure what `useImageEditor` and `useGooglePicker` return: their values are
reactive through getters, which destructuring reads only once.

### Example: image editor with `useImageEditor`

A minimal editor component. See [`useImageEditor`](#useimageeditor-file-) for
all the controls. The hook reads `file` once, so wrap the component in a
`{#key}` block when the file can change.

```svelte
<!-- ImageEditor.svelte -->
<script lang="ts">
  import type { UppyFile } from '@uppy/core'
  import { useImageEditor } from '@uppy/svelte'

  const { file, close }: { file: UppyFile<any, any>; close: () => void } =
    $props()

  const editor = useImageEditor({ file })
</script>

<img {...editor.getImageProps()} style="max-width: 100%" />
<input {...editor.getRotationSliderProps()} />
<button {...editor.getRotateButtonProps(90)}>Rotate</button>
<button {...editor.getFlipHorizontalButtonProps()}>Flip</button>
<button {...editor.getCropSquareButtonProps()}>Square</button>
<button {...editor.getResetButtonProps()}>Reset</button>
<button {...editor.getCancelButtonProps({ onClick: close })}>Cancel</button>
<button {...editor.getSaveButtonProps({ onClick: close })}>Save</button>
```

Render it inside an `UppyContextProvider` whose Uppy instance has the
`ImageEditor` plugin, for example from `<FilesList />`:

```svelte
<script lang="ts">
  import '@uppy/svelte/css/style.css'
  import '@uppy/svelte/css/image-editor.css'

  import Uppy, { type UppyFile } from '@uppy/core'
  import ImageEditor from '@uppy/image-editor'
  import { Dropzone, FilesList, UppyContextProvider } from '@uppy/svelte'
  import Editor from './ImageEditor.svelte'

  const uppy = new Uppy().use(ImageEditor)
  let editing = $state<UppyFile<any, any> | null>(null)

  function editFile(file: UppyFile<any, any>) {
    if (file.type.startsWith('image/')) editing = file
  }
</script>

<UppyContextProvider {uppy}>
  {#if editing}
    {#key editing.id}
      <Editor file={editing} close={() => (editing = null)} />
    {/key}
  {:else}
    <Dropzone />
    <FilesList {editFile} />
  {/if}
</UppyContextProvider>
```

### Example: Google Drive Picker with `useGooglePicker`

A button that opens Google Drive’s picker. Render it inside an
`UppyContextProvider` whose Uppy instance has the `GoogleDrivePicker` plugin,
set up as explained in the [Google Drive Picker docs](/docs/google-drive-picker):

```js
new Uppy().use(GoogleDrivePicker, {
  companionUrl: 'https://your-companion.com',
  clientId: 'From Google Developer Console',
  apiKey: 'From Google Developer Console',
  appId: 'From Google Developer Console',
})
```

For Google Photos, use `@uppy/google-photos-picker` and
`pickerType: 'photos'`. Add an uploader plugin, such as
[`@uppy/tus`](/docs/tus), to upload the picked files.

```svelte
<script lang="ts">
  import { useGooglePicker } from '@uppy/svelte'

  const drive = useGooglePicker({ pickerType: 'drive' })
</script>

<button type="button" disabled={drive.loading} onclick={() => drive.show()}>
  Import from Google Drive
</button>
{#if drive.accessToken}
  <button type="button" onclick={() => drive.logout()}>Sign out of Google</button>
{/if}
```
