:::warning Google Drive needs your own Google OAuth app

Transloadit’s shared Google OAuth app is blocked by Google, so the Google Drive
plugin does not work on Transloadit-hosted Companion with the default
credentials. Users get a Google page that says “This app is blocked”. To use
this plugin with hosted Companion you have to register your own Google OAuth app
and hand it to Companion as a Transloadit credential, see
[Use with Transloadit](/docs/google-drive#use-with-transloadit). The
[Google Drive Picker](/docs/google-drive-picker) plugin uses the non-restricted
`drive.file` scope, so it needs no Google verification, but it still needs your
own Google Cloud client ID, API key and app ID. Background:
[Navigating Google’s API changes](https://transloadit.com/blog/2025/02/the-new-google-situation/).

:::
