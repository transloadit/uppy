# Uppy documentation

Uppy is a modular JavaScript file uploader for web browsers. Start with the
[quick start](/docs/quick-start), then use these guides to assemble the upload
experience your application needs:

- [Choose an uploader](/docs/guides/choosing-uploader)
- [Build a full-featured Dashboard](/docs/dashboard)
- [Integrate React](/docs/react), [Vue](/docs/vue), [Svelte](/docs/svelte), or
  [Angular](/docs/angular)
- [Add remote sources through Companion](/docs/companion)
- [Browse working examples](/examples)

For instructions on linting or previewing these docs locally, see the
[uppy.io repository](https://github.com/transloadit/uppy.io).
